# FiveM iPhone Admin Phone

سكريبت هاتف ذكي (iPhone) متطور لـ FiveM يحتوي على قائمة إدارة شاملة.

## الميزات ✨

- 📱 واجهة هاتف iPhone احترافية
- ⚙️ قائمة إدارة متقدمة
- 🎨 تصميم عصري وجميل
- 🌐 دعم اللغة العربية الكامل
- ⌨️ اختصارات لوحة مفاتيح

## التثبيت 🔧

1. انسخ المجلد `ideal-dollop` إلى مجلد `resources` في سيرفرك
2. أضف هذا السطر إلى `server.cfg`:
```
ensure ideal-dollop
```

## الاستخدام 🎮

- **اضغط K** → فتح/إغلاق الهاتف
- **Admin** → الدخول إلى قائمة الإدارة
- **ESC** → إغلاق الهاتف

## الخيارات الإدارية 👨‍💼

- 👢 **طرد لاعب** - طرد اللاعب من السيرفر
- 🚫 **حظر لاعب** - حظر اللاعب من السيرفر
- 📢 **إعلان** - إرسال إعلان للجميع
- 📍 **نقل لموقع** - نقل لموقع معين

## المتطلبات 📋

- FiveM Server
- Lua 5.4+

## تطوير 👨‍💻

يمكنك تعديل الملفات حسب احتياجاتك:
- `client.lua` - منطق العميل (Client-side)
- `html/` - واجهة المستخدم
